# 🛒 EDokan - Full Stack E-Commerce Platform

EDokan is a modern full-stack e-commerce platform built to provide a seamless online shopping experience. It includes secure authentication, role-based dashboards, shopping cart management, order processing, and an integrated payment system.

---

## 🚀 Features

### 👤 Authentication
- User Registration
- User Login
- Secure Logout
- Role-Based Authentication
- Protected Routes

### 🛍️ User Features
- Browse Products
- Product Details
- Add to Cart
- Wishlist (Love Cart)
- Update Cart Quantity
- Remove Items from Cart
- Checkout System
- Online Payment Integration
- Order History
- User Dashboard
- Profile Management

### 👨‍💼 Admin Features
- Admin Dashboard
- Manage Products
- Manage Categories
- Manage Users
- Manage Orders
- Order Status Update
- Dashboard Analytics


## 💻 Technology Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

### Backend
- express.js 
- node.js


### Database
- MongoDB


### Payment
- Payment Gateway Integration
